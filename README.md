# LUSH-github

我的第一个 GitHub 仓库，用来跑通 clone → 修改 → 提交 → 推送 的完整流程。

## 环境

- Git 2.55.0（装在 `D:\Git`）
- 连接方式：SSH（ed25519 密钥）
- 默认分支：`main`

## 常用命令

| 目的 | 命令 |
| --- | --- |
| 看当前状态 | `git status` |
| 暂存全部改动 | `git add .` |
| 提交 | `git commit -m "feat: 说明"` |
| 推送 | `git push` |
| 拉取 | `git pull` |
| 看历史 | `git log --oneline --graph` |
